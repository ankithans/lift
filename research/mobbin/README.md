# Lift — Mobbin research

**77 original-resolution reference screens across iOS, Android and Web, from 18 product/platform collections.**

Direction: a quiet instrument for the next set. Pure black, neutral elevations, one mint accent, clear numbers, generous targets, explicit completion and a persistent rest timer. The interaction references include light-themed apps; the final Lift palette is defined in the spec.
